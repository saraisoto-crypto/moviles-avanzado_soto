# moviles-avanzado_soto# Programación en Móviles Avanzado — Sarai Soto

Repositorio de laboratorios semanales del curso.

## 🌿 Ramas

| Rama | Contenido |
|---|---|
| `main` | Estructura base de todas las semanas |
| `manual` | Ejercicios resueltos SIN asistencia de IA |
| `ai-assisted` | Ejercicios resueltos CON asistencia de IA |

## 📁 Estructura de carpetas

Cada semana tiene su propia carpeta (`SemanaXX`).

### Semana01 — Lab00: Integración Xcode-GitHub
Este laboratorio se realizó antes de definir el flujo de ramas `manual`/`ai-assisted`,
por lo que sus 3 versiones se conservan como carpetas separadas:
- `Lab00-Main`: versión base del proyecto
- `Lab00-Manual`: versión sin IA
- `Lab00-AiAssisted`: versión con IA

### Semana02 — Lab02: Condicionales y Bucles
A partir de este laboratorio se usa el flujo de ramas:
- Ejercicios 1-5: rama `manual` (sin IA)
- Ejercicios 6-7 + PROMPTS.md: rama `ai-assisted` (con IA)
