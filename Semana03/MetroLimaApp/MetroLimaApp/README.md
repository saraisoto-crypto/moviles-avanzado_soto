
# Metro Lima App

App de consola en Swift para consultar estaciones del Metro de Lima.

## Requerimientos funcionales
1. Listar estaciones (Línea 1, Línea 2 o ambas)
2. Buscar estación por nombre
3. Ver qué línea(s) cubren un distrito o lugar
4. Saber qué línea tomar según tu ubicación
5. Ver estaciones de transferencia (L1 <-> L2)
6. Calcular ruta y número de paradas entre dos estaciones

## Cómo correrlo
Desde Terminal, dentro de la carpeta del proyecto:

    swift run

O directamente en Xcode con el botón ▶.
