## Ejercicio 6 — Gestión de notas
### Prompt (CTRFE):
CONTEXTO: Soy estudiante de Programación en Móviles Avanzado, semana 3, aprendiendo colecciones en Swift (Arrays, Diccionarios, Sets).
TAREA: Crear un sistema que pida N alumnos con nombre y 3 notas cada uno usando un diccionario [String: [Double]], calcule el promedio de cada uno, lo clasifique con switch (Excelente/Bueno/Aprobado/Desaprobado), muestre estadísticas generales (promedio general, nota más alta/baja, % de aprobados) y ordene el ranking por promedio.
RESTRICCIONES: Solo usar conceptos vistos en semanas 1-3 (arrays, diccionarios, bucles, switch, readLine). No usar struct ni class.
FORMATO: Código Swift con un comentario explicando cada línea.
EJEMPLO: Diccionario [String: [Double]] donde la clave es el nombre y el valor es un array con 3 notas.

## Ejercicio 7 — Inventario con menú
### Prompt (CTRFE):
CONTEXTO: Mismo curso y semana, ya manejo diccionarios y sets en Swift.
TAREA: Crear un sistema de inventario que registre N productos (nombre, precio, stock) y luego muestre un menú interactivo con un bucle while con 5 opciones: ver inventario, buscar producto, ver stock bajo, calcular valor total y salir.
RESTRICCIONES: Solo conceptos de semanas 1-3, sin struct ni class, usar switch para el menú.
FORMATO: Código Swift con comentario en cada línea.
EJEMPLO: Menú tipo "1) Ver inventario 2) Buscar 3) Stock bajo 4) Valor total 5) Salir".
